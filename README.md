# CircuitBender

CircuitBender — это браузерный симулятор аналоговых синтезаторов. Приложение позволяет проектировать электрические схемы на холсте, симулировать их с помощью SPICE-движка (через WebAssembly) и воспроизводить полученный звук в реальном времени.

## Возможности

- Редактор схем на базе Konva (drag & drop).
- Точная симуляция цепей через `eecircuit-engine` (ngspice-wasm) в Web Worker.
- Воспроизведение звука через Web Audio API (AudioWorklet).
- Встроенный осциллограф и спектроанализатор.
- Режим калибровки: сравнение симуляции с реальной аудиозаписью.
- Экспорт схем в текстовый формат SPICE и аудио в WAV.
- Сохранение проектов в облако (Supabase).

## Стек

- **Frontend:** React 18, TypeScript, Vite
- **Графика:** Konva.js, uplot
- **Состояние:** Zustand
- **Аудио:** Web Audio API, AudioWorklet
- **Симуляция:** eecircuit-engine (WebAssembly)
- **Backend/BaaS:** Supabase

## Быстрый старт

1. Установите зависимости:
   ```bash
   npm install

2. Создайте файл .env.local в корне проекта и добавьте ключи от вашего проекта Supabase:
   VITE_SUPABASE_URL=ваш_url
   VITE_SUPABASE_ANON_KEY=ваш_anon_key
(Если пропустить этот шаг, приложение запустится, но функции сохранения в облако и авторизации будут недоступны).

3. Запустите dev-сервер:
   npm run dev

4. Откройте http://localhost:5173 в браузере.

## Настройка базы данных (Supabase)
Если вы хотите использовать облачное сохранение, выполните SQL-скрипт из файла supabase/schema.sql в SQL Editor вашего проекта Supabase. Это создаст таблицу projects и настроит политики безопасности (RLS).

## Скрипты
   npm run dev — запуск в режиме разработки.
   npm run build — сборка production-версии.
   npm run lint — проверка кода ESLint.
   npm run preview — локальный просмотр собранной версии.

## Деплой
Проект готов к деплою на Vercel. Файл vercel.json уже содержит необходимые настройки для SPA (одностраничного приложения). Не забудьте добавить переменные окружения VITE_SUPABASE_URL и VITE_SUPABASE_ANON_KEY в настройках проекта на Vercel.
